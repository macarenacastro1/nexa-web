# NEXA Automations · Landing page

Landing one-page para una agencia de automatizaciones con IA. Estética minimalista en negro, blanco y violeta.

Hecha con HTML, CSS y JavaScript puros, sin dependencias ni build.

## Ver en local
Abrí `index.html` en el navegador.

## Personalizar
En `main.js`, objeto `CONFIG`: nombre de la marca y número de WhatsApp.

## Publicar en GitHub Pages
Settings → Pages → Deploy from a branch → `main` / root.
